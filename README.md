# loveplate-2026

[LÖVE](https://love2d.org/) game boilerplate

## Folders

- `scenes/` — Game states / rooms (`demo.lua` is the starter scene)
- `entities/` — Game objects (`GameObject` subclasses) or entities in the ECS system
- `systems/` — Systems in the ECS system
- `lib/` — Third-party libraries
- `lib/alphonsus/` — Essential game infrastructure, generic and not game-specific
- `config/` — Game configuration tables
- `assets/` — Asset loader
- `particles/` — LÖVE particle preset tables

## Debugging

- Press `Tab` for FPS/entity count
- Press `` ` `` for collider overlay
